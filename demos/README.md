# Eniverse — kompletne podglądy demonstracyjne

Katalog zawiera siedem niezależnych, samodzielnych stron HTML przygotowanych z przesłanych przez użytkownika plików ZIP. W każdej wersji demo zasoby (CSS, JavaScript, zdjęcia i fonty) zostały osadzone w HTML, dzięki czemu nie wymagają WordPressa ani zewnętrznego katalogu assetów.

- `photographer.html` — Czuły Kadr
- `medical.html` — Próg
- `restaurant.html` — Półmisek
- `tradespeople.html` — OBWÓD
- `spa-salon.html` — Otulina
- `personal-trainer.html` — Morawa · Trener personalny
- `real-estate-agent.html` — Ida Rolewska

Strona główna `../index.html` używa tych projektów w galerii Abonament i Start oraz w kroku wyboru szablonu. Podglądy otwierają się wewnątrz ramki i w nowej karcie. Zdjęcia wbudowane w dema są zoptymalizowane; edytowalne oryginały pozostają w źródłowych ZIP-ach. Aby udostępnić publiczny link, włącz GitHub Pages dla gałęzi `main` z katalogu głównego (`/`).
